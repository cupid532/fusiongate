> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Architecture:** Preserve the existing APIs and routing semantics while correcting aggregation, propagating persistence errors, batching request-local key reads, and generating frontend assets inside CI and Docker. Every behavioral fix follows red-green-refactor testing.

**Tech Stack:** Go 1.25, SQLite WAL, React 19, TypeScript 6, Vite 8, Vitest, Docker BuildKit, GitHub Actions.
